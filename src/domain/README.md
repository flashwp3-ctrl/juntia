# Dominio

La 001 deja esta capa vacía de reglas financieras. Los tipos de dinero, contexto
de datos, persona y moneda llegan con P0-1 (maestro §15.10).

Regla del maestro §7.2: no importar `react`, `react-dom`, `next`, `motion`,
`@phosphor-icons/*`, `@radix-ui/*`, `@supabase/*` ni `@/components/*`.
El dominio no depende de la interfaz ni de SDK de proveedores.
